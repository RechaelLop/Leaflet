# 🍃 Leaflet – Smart Book Notes Generator

**Turn any book into actionable notes**

## 🎯 The Problem
You read great books. You highlight passages. Two weeks later? You remember almost nothing. Traditional summaries are too shallow to actually help you learn.

## 💡 The Leaflet Solution
Enter any book title + author → Leaflet uses Gemini AI to generate **structured, actionable notes** including key concepts, exercises, discussion questions, and a one-page cheat sheet.

## 🤖 How Leaflet Uses Gemini API

| Feature | How Gemini Powers It |
|---------|---------------------|
| **Multi-style notes** | Comprehensive, Actionable, Quick, or Deep Dive |
| **Concept extraction** | Identifies core ideas without generic fluff |
| **Actionable framing** | Converts theories into "what you can do Monday" |
| **Cheat sheet generation** | Distills entire book into one memorable paragraph |
| **Discussion questions** | Creates prompts for book clubs or self-reflection |

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- Google Gemini 1.5 Flash API
- No backend – runs entirely in browser
